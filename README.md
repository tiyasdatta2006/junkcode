🗓️ Daily Practice Workflow

My daily workflow follows these steps:

1. **Choose:** Select a problem based on my current DSA topic.
2. **Understand:** Identify the input, output, constraints, and edge cases.
3. **Solve:** Develop a straightforward solution before attempting optimization.
4. **Analyze:** Evaluate time and space complexity.
5. **Implement:** Write clean, readable, and well-structured code.
6. **Test:** Validate the solution against different test cases.
7. **Document:** Record the approach, complexity, and important observations.
8. **Commit:** Push meaningful changes to GitHub.
